# VibeForge — план роботи

## Де ми зараз (готово)

- **Веб-застосунок працює end-to-end**: React-чат зліва → FastAPI-бекенд → Gemini генерує повний HTML → живий прев'ю в iframe справа
- **Реальна AI-генерація** через безкоштовний рівень Google Gemini API (`GENERATOR=gemini`, ключ у `backend/.env`)
  - Модель: `gemini-3.6-flash`
  - Автоматичні повторні спроби при тимчасовому 503 "high demand" від Google (до 3 разів)
  - Виправлено баг: витягування HTML з відповіді більше не ламається, якщо згенерований JS сам містить зворотні лапки (template literals)
- **Ітеративне редагування**: наступні повідомлення в чаті редагують вже наявний сайт, а не починають з нуля (перевірено — "зроби кнопку синьою" спрацювало на реальному прикладі)
- **Завантаження готового сайту** як HTML-файлу
- Генератор схований за інтерфейсом (`GENERATOR=mock|gemini`), mock — для тестів без ключа

**Перевірено наживо**: згенеровано робочий лендінг "Borscht's Purple Hats" (магазин капелюхів з котом-талісманом) і сторінку кав'ярні з інтерактивним прогрес-баром — обидва виглядають професійно.

**Відомі обмеження:**
- Тільки **статичні односторінкові сайти** (HTML/CSS/JS в одному файлі, без бекенду) — свідомий вибір MVP, щоб не потрібен був складний sandbox для виконання коду
- Кнопки/елементи, що мали б вести на "іншу сторінку" (напр. "Enter Cafe"), нічого не роблять за замовчуванням — це один файл, немає концепції кількох сторінок. Можна попросити модель додати реальну інтерактивність (JS-обробники) конкретним промптом
- Безкоштовний рівень Gemini API іноді перевантажений (503) у пікові години — це обмеження з боку Google, не наш баг
- Історія проєктів зберігається тільки в межах поточної сесії браузера (немає окремого списку/галереї на сайті)

## Наступні кроки (за пріоритетом)

1. **Галерея проєктів** — список усіх створених сайтів на самому сайті (як ми зробили в AI 3D Forge)
2. **Кращий промпт-інжиніринг** — щоб генеровані сайти частіше мали робочу інтерактивність (кнопки, що щось роблять) без явного прохання
3. **Публікація в інтернет** — задеплоїти сайт, щоб інші люди могли ним користуватись
4. **Монетизація** — акаунти, ліміти генерацій, підписка

## Технічні борги

- Проєкт лежить у `~/Documents/vibeforge` (не плутати зі старим `~/Documents/ai-3d-forge` — два різні проєкти)
- Ключ Gemini у `backend/.env` (не в git) — якщо колись знадобиться новий, повтори процес отримання на aistudio.google.com/apikey
